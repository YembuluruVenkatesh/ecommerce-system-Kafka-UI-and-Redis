# Step 8: Check Consumer Exception Logs

The DLT message means the consumer threw an exception **before** processing.

Run:

```bash
docker logs inventory-service --tail 200
```

and

```bash
docker logs notification-service --tail 200
```

Look for lines like:

```text
Caused by:
The given id must not be null
```

or

```text
NullPointerException
```

---

## Most Likely Root Cause

Your consumer does:

```java
repository.existsById(event.getEventId())
```

If:

```java
event.getEventId() == null
```

the message goes to DLT.

So first run:

```sql
select id, payload, published
from outbox
order by id desc;
```

and paste the result here. That single query will tell us exactly whether the producer or consumer side is at fault.
